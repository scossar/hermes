*hermes.txt*   A Neovim chat client for Hermes Agent

CONTENTS                                                     *hermes-contents*

    2. Setup .................. |hermes-setup|

==============================================================================
1. Introduction                                          *hermes-introduction*

hermes.nvim connects Neovim to a `hermes serve` backend through a small Node
WebSocket bridge. One live conversation is rendered in a temporary Markdown
buffer. Hermes remains the canonical owner of session history and context.

==============================================================================
2. Setup                                                        *hermes-setup*

Requirements: Neovim 0.10+, Node.js 22+, and a reachable Hermes backend.

The default backend is http://127.0.0.1:9119. Call setup from your config: >lua
    require("hermes").setup({})
<
Override the bridge command when necessary: >lua
    require("hermes").setup({
      bridge_cmd = {
        "node",
        "/path/to/hermes.nvim/bridge/dist/bridge.js",
        "http://127.0.0.1:9119",
      },
    })
<
Configure tab-completion candidates for transcript export directories: >lua
    require("hermes").setup({
      transcript_directories = {
        "~/obsidian_vault",
        "~/projects/python/notes",
      },
    })
<
These are completion candidates, not an allowlist. Any existing directory can
be supplied directly.

==============================================================================
3. Commands                                                  *hermes-commands*

:Hermes {prompt}            Send a prompt to the current Hermes conversation.
                            The response streams into `hermes://chat`.

:Hermes                     Open the current chat buffer without sending.

:'<,'>HermesSendSelection   Send the current visual selection as a prompt.
                            This is suitable for a visual-mode mapping. It is
                            refused in the Compose buffer; use :HermesSubmit
                            there to send the complete draft.

:HermesStop                 Close the live Hermes session and bridge process.

:HermesInterrupt            Interrupt the active turn without closing the
                            durable conversation.

:HermesNew                  End the current live connection, clear its saved
                            local association, and create a new conversation.

:HermesSaveTranscript {path} {filename}
                            Save the complete `hermes://chat` buffer as a
                            Markdown file.

:'<,'>HermesSaveSelection {path} {filename}
                            Save the current visual selection as Markdown.

For both save commands, `.md` is appended when {filename} has no extension.
When the target exists, hermes.nvim asks whether to append, overwrite, or
cancel. Directories in `transcript_directories` are
offered through tab completion; other existing directories remain valid.

==============================================================================
4. Scope                                                        *hermes-scope*

The current development version supports one durable conversation, resumed
across Neovim restarts. It renders tool/reasoning events and uses vim.ui for
approvals and clarifications. Multiple simultaneous conversations and richer
buffer attachments remain deferred.
